# Dailogger iOS — 화면 구조 및 데이터 모델 (v1.0 기준)

초기 와이어프레임(`하루로그-wireframe.dc.html`) 설계에서 출발해 실제 출시 버전에 반영된
화면 구조와 데이터 모델을 정리한 문서입니다.

> 설계 대비 주요 변경: **무드 제거**, **모먼트 제목 제거**, **로그인·프로필 없음(완전 로컬)**,
> 릴 영상 2종·위젯·폰트 선택·리마인더 **추가**.

## 1. 앱 개요

- **컨셉**: 하루의 순간(모먼트)을 짧은 세로 영상으로 기록하면, 스토리로 돌려보고
  데일리 블로그·릴 영상으로 엮어주는 영상 일기 앱
- **핵심 루프**: 촬영 → 편집(캡션) → 저장 → 스토리로 감상 → 데일리 블로그 작성(선택: AI) → 릴 공유
- **디자인 언어**: 네오브루탈리즘 (잉크색 굵은 테두리, 하드 섀도우, 손글씨 폰트, 파랑/보라 포인트)
- **데이터**: 서버·계정 없음. SwiftData + 로컬 파일로만 저장

## 2. 내비게이션 구조

```
RootTabView (커스텀 하단 탭바, 중앙 녹화 FAB)
├── Today      (오늘 요약 + 오늘 모먼트)
├── Timeline   (전체 기록 — 날짜별 그룹)
├── Calendar   (월간 그리드 + 날짜 상세)
└── Me         (통계 + 블로그 아카이브 + 설정)

풀스크린 커버 (AppModel.Overlay):
- camera : FAB → 촬영
- edit   : 촬영 후 편집 / Viewer의 Edit
- viewer : 모먼트 탭 → 스토리 재생 (해당 날짜 범위로 스코프)
- blog   : 데일리 블로그 편집기/열람

공통 오버레이: Toast (2.4초 자동 소멸)
```

## 3. 화면별 명세

### 3.1 Today

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 헤더 | 날짜 라벨 + "Today" + 스트릭 필 | — |
| 히어로 카드 | 오늘 모먼트 수·총 길이, 썸네일 릴 6칸, "Create daily blog" | 버튼 → 블로그 편집기 |
| 모먼트 리스트 | 썸네일(70×98) + 길이 뱃지 + 시각 + 캡션 + 장소 | 탭 → Viewer, 길게 → 삭제 |

- **오늘 날짜의 모먼트만** 표시 (스트릭 계산은 전체 데이터 사용)

### 3.2 Timeline

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 헤더 | "Timeline" + 전체 모먼트 수 | — |
| 날짜 그룹 | 알약형 날짜 헤더("Today" / "Sat Jul 18"), 최신 날짜 우선 | — |
| 그룹 내부 | 좌측 시각 + 점선 세로축 + 보라 도트 + 미디어 카드 | 카드 탭 → 그 날짜 Viewer |

### 3.3 Calendar

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 헤더 | 월 타이틀 + 이번 달 기록 일수 | ◀ ▶ 월 이동 (미래 이동 불가) |
| 날짜 그리드 | 기록일=흰 배경+보라 도트, 오늘=파랑 테두리, 선택일=파랑 배경 | 기록일 탭 → 상세 갱신 |
| 상세 카드 | 날짜 + 클립 수·블로그 상태 + 9:16 썸네일 4칸 | 카드 탭 → 그 날 스토리, "Read the blog" → 블로그 |

### 3.4 Me

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 헤더 | "My Days" + ⚙️ 설정 | 폰트 변경 / 리마인더 on·off / 샘플 데이터 제거 |
| 통계 카드 | Streak · Blogs · Moments | — |
| 아카이브 그리드 | 3열 9:16 썸네일 + 날짜·클립 수 뱃지 | 탭 → 그 날 스토리, 길게 → 블로그 읽기 |

### 3.5 Camera

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 프리뷰 | AVCaptureSession 라이브 프리뷰 (시뮬레이터는 목 동작) | — |
| 상단 | 닫기 / REC 타이머 필 / 위치·시각 필 / 전·후면 전환 | — |
| 세그먼트 바 | 세그먼트별 흰 바 + 잔여 트랙 | 정지 시 세그먼트 추가 |
| 하단 | 갤러리 자리 / 녹화 버튼(원형↔사각) / 다음 | 다음: 녹화분 없으면 비활성 |

- 상태 머신: `idle → recording ↔ paused(세그먼트 누적) → edit`
- 권한: 카메라·마이크(필수), 위치(선택) — 거부 시 설정 이동 안내

### 3.6 Edit

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 프리뷰 | 병합 썸네일 + **실측** 길이 뱃지 | — |
| 캡션 | 여러 줄 입력 (로컬 상태, 저장 시 반영) | — |
| 위치·시각 | 자동 수집값 표시 | — |
| 저장 | "Save to timeline" → 병합 영상·썸네일 저장 | 신규 저장 또는 기존 모먼트 수정 |
| 삭제 | 기존 모먼트 편집 시에만 노출, 확인 다이얼로그 | 영상·썸네일 파일까지 삭제 |

### 3.7 Viewer (스토리)

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 진행 바 | **그 날짜** 모먼트 수만큼 분할, 0.1초 틱 | 영상 길이 기준 자동 진행 |
| 영상 | AVPlayerLayer 풀스크린 + 그라데이션 | 좌/우 탭 → 이전/다음, 0.25초 이상 홀드 → 일시정지 |
| 오버레이 | 시각·장소 필 + 캡션 박스 — **릴 영상과 동일한 위치·스타일** (상단 12%) | — |
| 액션 | 닫기(우상단), Edit(우하단) | — |

- 하나의 AVPlayer를 재사용(replaceCurrentItem)해 모먼트 전환 시 이전 오디오 즉시 정지

### 3.8 Blog (데일리 블로그)

| 구성 요소 | 내용 | 인터랙션 |
|---|---|---|
| 제목·본문 | 직접 입력/수정 (로컬 상태) | — |
| "Write with AI" | iOS 26+ Apple Intelligence 온디바이스 생성, 그 외 캡션 기반 템플릿 | 생성 후에도 수정 가능 |
| 클립 스트립 | 그 날 모먼트 썸네일 | — |
| 릴 만들기 | 타임라인 스타일 / 풀사이즈 스타일 2종 | 미리보기(AVKit) → ShareLink 공유 |
| 저장 | DailyLog에 제목·본문·AI 여부 저장 | — |

## 4. 데이터 모델 (실제 구현)

```swift
@Model final class Moment {
    var id: UUID
    var createdAt: Date            // 촬영 시각
    var title: String              // (legacy — UI 미사용)
    var caption: String
    var moodRaw: String            // (legacy — UI 미사용)
    var duration: TimeInterval     // 병합 파일에서 실측
    var placeName: String          // 역지오코딩 결과
    var latitude: Double?
    var longitude: Double?
    var videoFileName: String?     // Documents/Moments/ 상대 파일명
    var thumbnailFileName: String?
}

@Model final class DailyLog {
    var date: Date                 // 자정 기준
    var clipCount: Int
    var blogTitle: String?
    var blogText: String?
    var blogIsAI: Bool?
    var isBlogReady: Bool
}
```

- `title`·`moodRaw`는 초기 버전의 흔적으로 스키마에만 남아 있고 화면·릴·블로그 어디에도 쓰지 않음
- 모먼트↔로그는 관계 대신 **날짜 범위 쿼리**로 연결 (단순함 우선)
- 파생 값(스트릭·월 기록일·개수)은 매번 쿼리로 계산
- 영상·썸네일 파일은 `Documents/Moments/`에 저장, DB에는 파일명만 보관
- 위젯 공유 값(스트릭·오늘 클립 수)은 앱 그룹 UserDefaults로 전달
