# HaruLog iOS — 화면 분석 및 설계

와이어프레임(`하루로그-wireframe.dc.html`)을 기준으로 iPhone 네이티브 앱의 화면 구조, 컴포넌트, 데이터 모델을 분석·설계한 문서입니다.

## 1. 앱 개요

- **컨셉**: 하루의 순간(모먼트)을 짧은 세로 영상으로 기록하면, 자동으로 하나의 "데일리 블로그"로 엮어주는 영상 일기 앱
- **핵심 루프**: 촬영 → 편집(캡션·무드) → 타임라인 저장 → 데일리 블로그 생성 → 아카이브
- **디자인 언어**: 네오브루탈리즘 (잉크색 굵은 테두리, 하드 섀도우, 손글씨 느낌 폰트, 파랑/보라 포인트)

## 2. 내비게이션 구조

```
TabView (하단 탭바, 중앙 카메라 FAB)
├── Today      (오늘 요약)
├── Timeline   (오늘의 타임라인)
│   [중앙 FAB] → Camera (풀스크린 모달)
│                  └→ Edit (촬영 후 편집)
├── Calendar   (월간 기록)
└── Me         (프로필·아카이브)

공통 풀스크린 커버:
- Camera  : 탭바 FAB에서 진입
- Edit    : Camera "다음" 또는 Viewer "편집"에서 진입
- Viewer  : 모먼트 카드 탭 시 진입 (스토리 형식)
공통 오버레이:
- Toast   : 저장/블로그 생성 완료 피드백
```

## 3. 화면별 명세

### 3.1 Today (홈)

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 헤더 | 날짜 라벨 + "Today" 타이틀 | — |
| 스트릭 필 | 🔥 연속 기록 일수 | — |
| 히어로 카드 | 오늘 모먼트 수, 총 재생시간, 클립 릴(썸네일 6개), "Create daily blog" 버튼 | 버튼 탭 → 블로그 생성 → 토스트 |
| 모먼트 리스트 | 카드: 세로 썸네일(70×98) + 재생시간 뱃지 + 시각 + 무드 필 + 제목 + 장소 | 카드 탭 → Viewer |

- 데이터: 오늘 날짜의 `Moment` 목록, 스트릭 수치
- 빈 상태(신규 유저): 모먼트 0개일 때 촬영 유도 문구 필요 (와이어프레임에 없음 → 추가 설계)

### 3.2 Timeline

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 헤더 | "Timeline" + 날짜·모먼트 수 | — |
| 타임라인 | 좌측 시각 라벨 + 점선 세로축 + 보라 도트 | — |
| 모먼트 카드 | 미디어 영역(150pt, 재생 버튼·재생시간) + 제목 + 무드 필 + 캡션 | 카드 탭 → Viewer |

### 3.3 Calendar

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 헤더 | 월 타이틀("July 2026") + 이번 달 기록 일수 | 월 전환(스와이프/버튼) — 추가 설계 |
| 요일 헤더 | S M T W T F S | — |
| 날짜 그리드 | 셀(비율 1:1.28): 기록일=흰 배경+도트, 오늘=파랑 테두리, 선택일=파랑 배경 | 기록일 탭 → 하단 상세 갱신 |
| 일자 상세 카드 | 선택일 + 모먼트 수·블로그 상태 + 클립 릴(9:16 썸네일 4개) | 릴 탭 → 해당 일의 Viewer — 추가 설계 |

### 3.4 Me (프로필)

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 프로필 헤더 | 아바타, 닉네임, 핸들, 설정 버튼 | 설정 → 설정 화면 (추가 설계) |
| 통계 카드 | Streak / Blogs / Moments 3분할 | — |
| 아카이브 그리드 | 3열, 9:16 썸네일 + 날짜 뱃지 + 클립 수 뱃지 | 셀 탭 → 해당 일 블로그 재생 |

### 3.5 Camera (풀스크린 모달)

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 프리뷰 | 카메라 실시간 프리뷰(전체) + 상하 그라데이션 | — |
| 상단 컨트롤 | 닫기 / REC 타이머 필(녹화 중 도트 펄스) / 위치·시각 필 / 카메라 전환 | 닫기 → dismiss, 전환 → 전·후면 토글 |
| 세그먼트 바 | 녹화된 세그먼트별 흰 바 + 잔여 트랙 | 녹화 정지 시 세그먼트 추가 |
| 무드 칩 | 가로 스크롤 칩 6종 (선택 시 보라 배경) | 탭 → 선택 |
| 하단 컨트롤 | 갤러리 / 녹화 버튼(대기: 원형 → 녹화: 사각) / 다음 버튼 | 다음: 녹화분 없으면 비활성+토스트 |

- 상태 머신: `idle → recording → paused(세그먼트 누적) → (다음) → edit`
- 권한: 카메라·마이크·위치 권한 요청 플로우 필요

### 3.6 Edit (모먼트 편집)

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 헤더 | 뒤로 + "Edit moment" (sticky) | 뒤로 → Camera 또는 Viewer로 복귀 |
| 프리뷰 | 9:16 미리보기 + 재생시간 뱃지 | 탭 → 재생 (추가 설계) |
| 캡션 | 여러 줄 입력 | 키보드 회피 처리 |
| 무드 | 칩 6종 (선택 시 보라+하드섀도우) | 탭 → 선택 |
| 위치·시각 | 자동 수집값 표시 행 2개 | 탭 → 수정 (추가 설계) |
| 저장 버튼 | "Save to timeline" | 저장 → Today 복귀 + 토스트 |

### 3.7 Viewer (스토리 뷰어)

| 구성 요소 | 내용 | 상태/인터랙션 |
|---|---|---|
| 진행 바 | 모먼트 수만큼 분할, 현재까지 흰색 | 자동 진행(영상 길이 기준) |
| 영상 | 풀스크린 재생 + 그라데이션 | 좌/우 탭 → 이전/다음, 길게 → 일시정지 |
| 정보 | 시각, 무드, 제목, 캡션, 장소 | — |
| 액션 | 닫기, Edit 버튼 | Edit → Edit 화면 |

### 3.8 공통

- **Toast**: 하단 잉크색 바 + 체크 아이콘, 2.4초 후 자동 소멸, 등장 애니메이션
- **햅틱**: 녹화 시작/정지, 저장, 탭 전환에 경량 햅틱
- **다크 모드**: 1차 릴리즈 라이트 고정, 2차에서 대응

## 4. 데이터 모델 (초안)

```swift
@Model final class Moment {
    var id: UUID
    var createdAt: Date          // 촬영 시각
    var title: String
    var caption: String
    var mood: Mood               // enum: fresh/calm/happy/peaceful/moved/proud
    var duration: TimeInterval
    var videoURL: URL            // 로컬 파일 (세그먼트 합본)
    var thumbnailURL: URL?
    var placeName: String?       // 역지오코딩 결과
    var latitude: Double?
    var longitude: Double?
    var dailyLog: DailyLog?      // 소속 일자
}

@Model final class DailyLog {
    var date: Date               // 일 단위 (자정 기준)
    @Relationship(deleteRule: .cascade) var moments: [Moment]
    var blogText: String?        // AI 생성 블로그 본문
    var blogVideoURL: URL?       // 합본 릴 영상
    var isBlogReady: Bool
}

@Model final class UserProfile {
    var nickname: String
    var handle: String
    var avatarURL: URL?
    var streakCount: Int         // 파생값 캐시
}
```

- 파생 값: 스트릭(연속 기록일), 월간 기록일 수, 총 모먼트 수 → 쿼리로 계산, 프로필에 캐시
- 영상 파일: 앱 컨테이너 `Documents/Moments/` 저장, DB에는 상대 경로 보관
