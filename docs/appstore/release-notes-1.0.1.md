## 상세 변경 내역 (개발자용)

### 새 기능
- 카메라 줌: 듀얼 광각 가상 카메라로 0.5x/1x/2x 전환 (초광각 없는 기기는 1x/2x)
- 플래시(토치) 토글 — 후면 전용, 전면 전환 시 자동 꺼짐
- 사진첩 불러오기: 사진(3초 정지 클립 변환)·영상 가져오기 (PhotosPicker)
- 5초 초과 영상 트림 화면 — 구간 슬라이더 + 반복 미리보기
- 촬영 5초 제한: 타이머 자동 정지 + 파일 레벨 백스톱, 비율형 세그먼트 바
- 위젯 중간 크기(systemMedium) 추가 — 스트릭 | 오늘 클립 수 2열
- 과거 날짜 스토리 재생: 캘린더 날짜 카드·Me 탭 아카이브에서
- 캘린더: 블로그 없는 날짜도 선택·모먼트 확인, "이날의 블로그 쓰기"로 과거 일기 작성
- 캘린더 카드 썸네일 5개 이상 가로 스크롤, 썸네일 탭 → 해당 모먼트부터 재생
- 타임라인 탭이 전체 기록을 날짜별 그룹으로 표시 (기존: 오늘만)
- 브랜드 런치 스크린 (종이색 배경 + 카메라 배지)

### 개선
- AI 블로그: 최대 10단어 SNS/MZ 톤 캡션으로 (템플릿 폴백 동일 톤)
- 블로그 편집기 본문 입력란 2줄로 축소
- 릴 레이아웃: 블로그 문구는 카드 푸터(없으면 캡션이 대신), 캡션은 영상 위 흰 박스
- 릴 텍스트 이모지 렌더링 (이모지 구간 Apple Color Emoji 강제)
- 릴에서 사진첩 클립 회전·크기 정상화 (클립별 transform 적용)
- 스토리 뷰어: 가로 영상 레터박스 (잘림 방지)
- 전면 카메라 미러 저장 (프리뷰와 일치)
- 재생 오디오 세션 활성화 — 무음 스위치/촬영 직후에도 소리 정상
- 성능: 타임라인 LazyVStack, 길이 재측정 1회화, Me 탭 아카이브 스캔 캐시
- 입력 위생: 보이지 않는 제어문자 제거 + 길이 제한 (캡션 150/제목 60/본문 300)

### 버그 수정
- 달력 1·2일 누락 및 요일 밀림 (LazyVGrid ID 충돌)
- 투데이/타임라인/스토리 뷰어가 다른 날짜 모먼트를 섞어 보여주던 문제
- 영상 길이가 항상 5초로 저장되던 문제 (실측 저장 + 기존 데이터 자동 교정)
- 스토리 마지막 모먼트 후 다른 날 영상 소리가 나던 문제
- 자동 캡션 문구 제거 (빈 캡션은 빈 채로)
- 중복 생성된 데일리 블로그 자동 정리
- 샘플 데이터 제거 (신규 설치 빈 상태 시작, 기존 기기 자동 정리)
