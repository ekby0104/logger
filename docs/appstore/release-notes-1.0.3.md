# 1.0.3 (빌드 7) 변경사항

## App Store "이 버전의 새로운 기능" (붙여넣기용)

```
🎬 릴 영상이 유튜브 쇼츠·인스타 릴스에서 잘리지 않도록 개선했어요.
사진첩에서 가져온 영상이 섞여 있어도 항상 9:16 비율로 만들어집니다.
```

## 상세 변경 내역 (개발자용)

### 버그 수정
- **릴 캔버스 9:16 고정** — 캔버스 크기를 첫 번째 클립 해상도로 잡고 있어서,
  사진첩에서 가져온 영상(아이폰 화면 비율 9:19.5 등)이 첫 클립이면 릴 전체가
  9:16보다 세로로 길게 만들어졌고, 쇼츠·릴스가 이를 확대·크롭하면서 점선 레일,
  시간 라벨, 카드 가장자리가 잘려 보였습니다. 이제 항상 1080×1920으로 렌더링하고
  각 클립은 캔버스에 맞춰 채워집니다.

### 문서
- 저장소 이름 변경(`ekby0104/logger` → `yuemyname/dailogger`) 반영
- 출시 체크리스트 현행화 (1.0/1.0.1/1.0.2 승인 완료 상태)

### 버전
- MARKETING_VERSION 1.0.3 / CURRENT_PROJECT_VERSION 7 (앱·위젯 두 타깃 동일)
